# flq web player

Browser player for `.flq` files. Decoding runs locally in
WebAssembly — nothing is uploaded.

- Drag a `.flq` in anywhere on the page, or use **Open file** / **demo** /
  **stems** (8-track synthetic session, ~17% of raw PCM — shows off
  multi-track mixing and per-track ratios).
- Layers tab: one row per track — enable/solo in the mix, per-track volume,
  live waveform, coded size + ratio, WAV export.
- Waveform: overview of the focused track with click/drag seek.
- Info: full file/track metadata (origin, nframes, coded bytes, pcm_crc).
- Stats chips under the transport: file size, ratio vs PCM, frame/index
  info, live decode speed and buffer-ahead; focused-layer scope + peak
  meter in the transport bar.
- Space = play/pause, arrows = seek ±5 s / volume, L = loop.

## Build locally

```powershell
rustup target add wasm32-unknown-unknown   # once
.\wasm\build.ps1                            # produces web\flq_wasm.wasm
python -m http.server -d web 8000           # then open http://localhost:8000/
```

`wasm/build.sh` is the equivalent on Unix. The bundled samples
(`samples/demo.flq`, `samples/stems.flq`) are regenerated by
`cargo test --release -- --ignored gen_web_demo`.
