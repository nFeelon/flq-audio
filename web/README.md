# flq web player

Browser player for `.flq` files. Decoding runs locally in
WebAssembly — nothing is uploaded.

- Drag a `.flq` in, or click **load sample** for the bundled 2-track demo.
- Per track: mute/solo, format/rate/duration/PCM size, **wav** download.
- Streaming playback: ~2 s chunks decoded per track and scheduled ahead.

## Build locally

```powershell
rustup target add wasm32-unknown-unknown   # once
.\wasm\build.ps1                            # produces web\flq_wasm.wasm
python -m http.server -d web 8000           # then open http://localhost:8000/
```

`wasm/build.sh` is the equivalent on Unix. The demo is regenerated by
`cargo test --release -- --ignored gen_web_demo`.
